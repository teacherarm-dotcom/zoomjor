# ZoomJor (ซูมจอ)

โปรแกรมช่วยนำเสนอ/สอนบน macOS — **ซูมหน้าจอ · วาดทับหน้าจอ · ซูมสด · นาฬิกาจับเวลาพัก**
ทำงานคล้าย ZoomIt ของ Sysinternals เขียนด้วย Swift/AppKit ล้วน ไม่ต้องติดตั้งไลบรารีเพิ่ม
เป็นแอปบนแถบเมนู (menu bar)

📄 **คู่มือใช้งาน 1 หน้า (คีย์ลัดครบทุกโหมด · ปริ้นต์ได้):** [`docs/guide.html`](docs/guide.html)

---

## คอมไพล์ / ติดตั้ง

```bash
./build.sh
```

ได้ `ZoomJor.app` — ลากไปไว้ที่ `/Applications` แล้วดับเบิลคลิกเปิด
ไอคอนจะไปโผล่บนแถบเมนูด้านขวาบน

### ใส่ไอคอนของตัวเอง

| ไฟล์ | ใช้เป็น |
|---|---|
| `Resources/AppIcon.icns` | ไอคอนแอป (Finder / Dock / About) |
| `Resources/MenuBarIcon.pdf` หรือ `.png` | ไอคอนบนแถบเมนู — ควรเป็นขาวดำพื้นโปร่งใส ~18×18 pt (macOS จะย้อมสีตามธีมให้เอง) |

ตอนนี้ใช้ไอคอนจาก `zoomjor icon.png` แล้ว · ถ้าจะเปลี่ยนใหม่ ให้แปลงเป็น `.icns` ด้วย:

```bash
./make-icon.sh ~/Desktop/zoomjor-1024.png
```

แล้วสั่ง `./build.sh` ใหม่ ถ้าไม่ใส่ไฟล์ไอคอน โปรแกรมจะใช้สัญลักษณ์แว่นขยายของระบบแทน

> ครั้งแรกที่ใช้ **โหมดซูม (⌃1)** หรือ **ซูมสด (⌃4)** macOS จะขอสิทธิ์ *การบันทึกหน้าจอ (Screen Recording)*
> อนุญาตที่ **การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การบันทึกหน้าจอ** แล้วเปิดแอปใหม่
> (โหมดวาด ⌃2 ใช้ได้เลยโดยไม่ต้องขอสิทธิ์)

## ⌨️ คีย์ลัดใช้ได้ทั้งแป้นไทยและอังกฤษ

คีย์ลัดทุกตัวอ่านจาก **ตำแหน่งปุ่มจริง** (key code) ไม่ใช่ตัวอักษรที่พิมพ์ออกมา
สลับแป้นพิมพ์เป็นภาษาไทยค้างอยู่ก็กดได้ตามปกติ **ไม่ต้องสลับกลับเป็นอังกฤษ**

> ปุ่มที่เขียนว่า `R` = ปุ่มเดียวกับ `พ` · `A` = ปุ่มเดียวกับ `ฟ` · `U` = ปุ่มเดียวกับ `ี`
> รวมถึงตัวเลขตั้งเวลาในโหมดนาฬิกาด้วย

## 🧰 แถบเครื่องมือบนจอ — คลิกได้ ไม่ต้องจำคีย์

พอเข้าโหมดใด ๆ จะมีแถบลอยกลางจอด้านบน กดเลือกได้ทั้งหมด:

`ลูกศร · ปากกา · เส้นตรง · สี่เหลี่ยม · วงรี · ไฮไลต์ · ข้อความ` │ `สี 8 สี` │ `↶ ย้อนกลับ · ↷ ทำซ้ำ · 🗑 ลบทั้งหมด` │ `✕ ออก`

ชี้ค้างที่ปุ่มจะขึ้นชื่อปุ่มให้ · กด `D` เพื่อซ่อน/แสดงแถบ

## ↩️ วาดผิด — ย้อนกลับได้ 4 ทาง

| วิธี | หมายเหตุ |
|---|---|
| `⌫` (Backspace) | สั้นที่สุด กดรัวได้ |
| `⌘Z` | มาตรฐาน macOS |
| `U` | ปุ่มเดียว |
| ปุ่ม `↶` บนแถบเครื่องมือ | ใช้เมาส์ล้วน |

ทำซ้ำ = `⇧⌘Z` · ลบทั้งหมด = `E` หรือ `⌘⌫` — **การลบทั้งหมดย้อนกลับได้ด้วย** (เก็บย้อนหลังได้ถึง 300 ขั้น)

## คีย์ลัดเรียกใช้งาน (กดที่ไหนก็ได้)

| คีย์ | โหมด |
|---|---|
| `⌃1` | **ซูม** — แช่หน้าจอแล้วขยาย + วาดทับได้ |
| `⌃2` | **วาด** — วาดทับหน้าจอสด ๆ |
| `⌃3` | **นาฬิกาจับเวลาถอยหลัง** — หน้าจอพักเบรก |
| `⌃4` | **ซูมสด (Live zoom)** — ขยายภาพจริงแบบเรียลไทม์ ใช้แอปข้างล่างต่อได้ |

กดคีย์เดิมซ้ำ = ออกจากโหมด

## โหมดซูม (⌃1)

| คีย์ | ทำอะไร |
|---|---|
| เลื่อนเมาส์ | ส่องภาพตามตำแหน่งเมาส์ |
| สกอร์ล / `+` `-` / `↑` `↓` | ขยาย–ย่อ (1×–16×) |
| `0` | กลับไป 100% |
| คลิกลาก | เริ่มวาด (ภาพจะล็อกอัตโนมัติ) |
| `Tab` | สลับล็อก/ปลดล็อกการแพนตามเมาส์ |
| `←` `→` | เลื่อนภาพซ้าย–ขวา |
| `Esc` / คลิกขวา | ออก |

## โหมดซูมสด — Live zoom (⌃4)

ขยายภาพหน้าจอ **แบบเรียลไทม์** ต่างจาก ⌃1 ตรงที่ไม่แช่ภาพ และ **คลิก/พิมพ์ทะลุลงไปยังแอปข้างล่างได้ตามปกติ**
จุดที่อยู่ใต้เคอร์เซอร์จะถูกตรึงไว้กับที่ — คลิกตรงไหนก็โดนตรงนั้นจริง

| คีย์ / ปุ่ม | ทำอะไร |
|---|---|
| `⌃⌥↑` หรือ `⌃⌥=` | ขยาย |
| `⌃⌥↓` หรือ `⌃⌥-` | ย่อ |
| `⌃⌥0` | กลับ 200% |
| แถบลอยด้านบนจอ | ปุ่ม `−` `+` และ `✕` (กดได้โดยไม่แย่งโฟกัสจากแอปที่ใช้อยู่) |
| `⌃4` | ปิด |

> คีย์ `⌃⌥…` จะถูกจองเฉพาะตอนซูมสดทำงาน แล้วคืนให้ระบบเมื่อปิด

## โหมดนาฬิกาจับเวลาถอยหลัง (⌃3)

หน้าจอพักเบรกเต็มจอ พื้นหลังเป็นภาพหน้าจอที่เบลอ + หรี่แสง พร้อมวงแหวนนับถอยหลัง
และบอกเวลาที่จะกลับมาต่อ เมื่อหมดเวลาจะมีเสียงเตือนและตัวเลขกะพริบสีแดง

| คีย์ | ทำอะไร |
|---|---|
| `Space` | หยุด / เดินเวลาต่อ |
| `↑` `↓` | ±1 นาที |
| `←` `→` | ±10 วินาที |
| พิมพ์ตัวเลข + `Enter` | ตั้งเวลาใหม่ (นาที) |
| `⌘R` | เริ่มนับใหม่ |
| `D` | เปิด/ปิดแถบเครื่องมือ |
| `Esc` | ออก |

ตั้ง **เวลาพักเริ่มต้น** ได้จากเมนูบนแถบเมนู (จำค่าไว้ให้) และยังวาดลูกศร/ข้อความทับหน้าจอพักได้ด้วย

## เครื่องมือวาด

| คีย์ | เครื่องมือ |
|---|---|
| `a` | ลูกศร |
| `p` | ปากกาวาดอิสระ (ค่าเริ่มต้น) |
| `l` | เส้นตรง |
| `s` | สี่เหลี่ยม |
| `c` | วงรี |
| `h` | ปากกาไฮไลต์ (โปร่งแสง) |
| `t` | ข้อความ — คลิกแล้วพิมพ์, `Enter`/`Esc` จบ |

**ทางลัดขณะลาก (ไม่ต้องเปลี่ยนเครื่องมือ):** `⇧` ค้าง = ลูกศร · `⌃⇧` ค้าง = สี่เหลี่ยม · `⌥` ค้าง = บังคับมุม 45° / จัตุรัส

## หมายเหตุ

- ทำงานบน **จอที่เมาส์อยู่** ขณะกดคีย์ลัด (รองรับหลายจอ ทีละจอ)
- ภาพวาดเก็บเป็นพิกัดของหน้าจอ จึง **เกาะตำแหน่งเดิมเมื่อซูม/เลื่อน**
- ภาพที่แช่ไว้จับที่ความละเอียด Retina เต็ม ซูมแล้วยังคมชัด
- คีย์ลัดจองผ่าน Carbon `RegisterEventHotKey` จึง **ไม่ต้องขอสิทธิ์ Accessibility**
- ถ้าแอปอื่นจอง `⌃1`–`⌃4` ไว้ จะมีแจ้งเตือนตอนเปิด — สั่งงานผ่านเมนูบนแถบเมนูแทนได้
